# Embellish Studio

Small brochure-style website for a Chesterfield hair salon, built in Astro with
light Alpine.js interactions and a server-backed bridal enquiry endpoint.

## Stack

- Astro for server-rendered pages
- Alpine.js for lightweight UI behavior
- Astro Node adapter for form handling

## Commands

All commands run from `/Users/lukebrobbin/Development/personal-projects/embellish`.

- `npm install`
- `npm run dev`
- `ASTRO_TELEMETRY_DISABLED=1 npm run build`
- `npm run astro check`

## Content

Structured site content lives in [`src/data/site.ts`](./src/data/site.ts).
The current visuals are launch-ready placeholders in [`public/media`](./public/media)
and are designed to be replaced with real salon photography, reels, and bridal imagery.
